## Contraintes retenues

Windows 10/11, Chrome/Edge récents constituent la cible prioritaire, à vérifier sur matériel. Le navigateur utilise les périphériques exposés par Windows, pas un accès ASIO exclusif. Le CLP-825 annonce USB Audio 44,1 kHz/24 bits/stéréo ; les réglages réellement reçus peuvent être rééchantillonnés et doivent être affichés. Yamaha documente un pilote USB pour Windows : aucune promesse universelle « sans pilote ».

Aucun retour logiciel de l’entrée piano n’est réactivé par défaut. Le piano produit son écoute directe ; les accompagnements disposent de leur propre bus de lecture. Audio Loopback doit être désactivé pour éviter de capturer l’accompagnement dans le piano puis de l’ajouter une seconde fois au mix.

Sources : manuel CLP-825 et guide Yamaha Computer-related Operations ; documentation Chrome AudioContext.setSinkId. Les vérifications de simulation restent identifiées comme telles.
